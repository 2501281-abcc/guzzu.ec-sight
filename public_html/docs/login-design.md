# ログイン画面の設計書

第7回の課題（初級）。

## ① ログイン画面の入力項目

| 項目 | 入力形式 | 必須 |
|---|---|---|
| メールアドレス | email | ○ |
| パスワード | password（入力中は `•` で隠れる） | ○ |
| ログインボタン | submit | ― |

- 入力形式は、HTMLの `<input type="…">` の種類で書く。
- 必須なら `○` と書く。

## ② 処理の流れ

```mermaid
flowchart TD
    A["メールとパスワードを入力して送信"]
    B["メールアドレスで users テーブルを検索"]
    C{"ユーザーがいる？"}
    D{"パスワードが一致する？"}
    E["「メールアドレスまたはパスワードが違います」と表示"]
    F["$_SESSION に user_id を保存"]
    G["マイページへ移動"]
    H["ログイン画面に戻る"]

    A --> B
    B --> C
    C -->|はい| D
    C -->|いいえ| E
    E --> H
    D -->|はい| F
    D -->|いいえ| E
    F --> G
```
